# Double Straddle Earnings Backtest

Calendar straddle strategy backtested across 25 large-cap stocks (2016–2026).

**Strategy:** 7 days before each earnings date —
- **SELL** a near-term ATM straddle (expires 2–7 days after earnings)
- **BUY** a far-term ATM straddle (expires past the *next* earnings date)

Exit the short leg at expiry (intrinsic value). Exit the long leg one trading day before next earnings to capture IV expansion.

---

## Setup

**Requirements:** Python 3.10 or higher

### 1. Clone the repo

```
git clone https://github.com/Redbottlerocket/Double-Straddle-Test.git
cd Double-Straddle-Test
```

### 2. Create a virtual environment

**Mac / Linux:**
```
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

---

## Running the strategy

All scripts are in the `strategy/` folder. Run them from the **project root** (not from inside `strategy/`).

**Mac / Linux:**
```
python strategy/backtest.py          # recompute trades → results/trades.csv
python strategy/report.py            # performance summary
python strategy/daily_greeks.py      # recompute Greeks → results/daily_greeks.parquet
python strategy/_annual_returns.py   # annual P&L table
python strategy/_payout_charts.py    # payout pattern charts → results/payout_patterns.png
python strategy/_sensitivity_exit.py # exit timing sweep → results/sensitivity_exit.png
python strategy/_hedge_check.py      # hedge correlation analysis
python strategy/_greek_phases.py     # Phase 1 vs Phase 2 Greek breakdown
python strategy/_moneyness_vega.py   # ATM vs OTM/ITM vega comparison
```

**Windows:**
```
python strategy\backtest.py
python strategy\report.py
... (same pattern)
```

> `backtest.py` and `daily_greeks.py` take a few minutes to run. All other scripts are fast.

## Data

Option price data sourced from **Databento OPRA.PILLAR** (same feed as TOS ThinkBack).
All fills use mid-price (optimistic). See `docs/adr/0001-mid-price-for-fills.md`.

Greeks computed via Black-Scholes with continuous dividend yield and time-varying
3-month T-bill rates. See `docs/adr/0002-black-scholes-for-greeks.md`.
